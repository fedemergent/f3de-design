TMS Library Manager

Gestor de bibliotecas · desarrollo a medida para The Millwork Studio

Un solo clic para tener el estudio al día: publica desde la PC maestra, sincroniza las bibliotecas de bloques dinámicos y tool palettes en cada equipo e importa el perfil de grupos XPG, con avisos de las últimas actualizaciones del equipo.

  • Millwork drafting
  • Gestión de bibliotecas
  • Sincronización en la nube
  • Control de versiones

Descarga preliminar

TATU para Rhino · v1.1.4

Ingresa tu correo para descargar el instalador (Windows, ). Recibirás un aviso cuando haya nuevas versiones.

¡Gracias!

Tu descarga está en camino

Si no empieza sola, haz clic aquí.

  1. Cierra Rhino y ejecuta TATU_Setup.exe.
  2. Si Windows muestra «Windows protegió su PC» (el instalador aún no está firmado), elige Más información → Ejecutar de todos modos.
  3. Abre Rhino: verás la barra de TATU. Escribe el comando TATU si no aparece.
