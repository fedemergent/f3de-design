# F3DE Design

Sitio web de **F3DE Design** (Federico Escobar): diseño industrial, plugins para Rhino, tutoriales, cursos y servicios.

- Sitio: https://fedemergent.github.io/f3de-design/
- Plugin TATU para Rhino: https://github.com/fedemergent/tatu-rhino

## Editar
- Textos y secciones: `index.html`. Certificados: `certificados.html`.
- Estilos: `assets/site.css`. Scripts: `assets/common.js`.
- Configuración (correos, descarga de TATU): `assets/config.js`.
- Guardar los correos en Google Sheets: ver `google-sheet/LEEME.md`.
- Modelos 3D: exporta a `.glb` desde Rhino, ponlo en `assets/modelos/` y agrégalo a la lista `MODELS` de `index.html`.

Para probarlo en tu PC, abre `ver-web-local.bat` (hace falta Python).
